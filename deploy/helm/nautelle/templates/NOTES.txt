First run: open the one-time setup link the API logs and create the first
administrator (each API start logs a new one):

  kubectl -n {{ .Release.Namespace }} logs deploy/{{ $fullname }}-api | grep -o 'http[^ ]*/setup?token=[^ ]*' | tail -n 1

  nautelle-runner pair --server {{ $url }}/api --code XXXX-XXXX --allow-root ~/dev
