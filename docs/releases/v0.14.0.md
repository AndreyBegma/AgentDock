# AgentDock v0.14.0

Released 2026-10-20 · Runner: 0.13.0 (unchanged in this window) ·
Changelog entry: `packages/shared/src/changelog.ts`

## Summary

The first release with a version. AgentDock now has a release process: a
changelog shown on a What's new page, with a dot in the account menu until a
person has read it. The version starts at 0.14.0, independent of the runner's
0.13.0. The rest of the release is the S-7 redesign: a project's navigation is
cut to five entries with the Board first, and most pages move to one calmer
layout that also fits a tablet and a phone.

This release has no earlier tag, so its window is everything merged into
`develop` since the last promotion to `main`
([#682](https://github.com/AndreyBegma/Nautelle/pull/682), 2026-10-19), plus
the release process itself.

## What changed

### New

- AgentDock has versioned releases, and What’s new in the account menu shows what each one brought.

### Improved

- A project has five places in its navigation, with the Board first and everything else one tap away.
- The project home, Fleet, Activity, settings, Planner, Schedules, Skills and Token saver pages share one calmer layout, and so do Overview, Projects and Work.
- History is now part of a project’s Activity, so everything that happened is in one place.
- Tablets get a layout of their own, and on a phone New work, the design viewer and the terminal close from one back bar at the bottom of the screen.

### Fixed

- Design mockups with many frames are no longer refused for their size, and a frame whose script cannot run is turned away with a reason.
