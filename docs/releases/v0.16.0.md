# Nautelle v0.16.0

Released 2026-10-24 · Runner: 0.16.0, released with this version (`runner-v0.16.0`, cut from the same `main` commit) ·
Changelog entry: `packages/shared/src/changelog.ts`

## Summary

Nautelle now installs like a mature self-hosted product. One command pulls the published images and starts it on localhost, behind a Cloudflare tunnel or on your own domain with HTTPS. The keys are generated on first boot, and you create the first admin in the browser. A Helm chart and a documentation site come with it.

A finished card that changes the UI can now carry a demo video. The runner records it with DemoFlow, and you watch it on the card or in Telegram before you merge. Projects can also run review steps before a card counts as Finished.

**Upgrade:**
- Update every runner to 0.16.0 (`nautelle-runner update`, or `npm i -g nautelle-runner@0.16.0`). Demo videos need Node.js 22 or later on the runner's machine.
- To record demos in a project, turn on *Settings → Automation → Demo videos* and add a `demoflow.config.json` to the repository.
- Back up the API's `/data` volume together with the database. It now holds the generated keys.

## What changed

### New

- Nautelle installs with one command from published images, on localhost, behind a Cloudflare tunnel or on your own domain with HTTPS, and you create the first admin in the browser.
- A finished card that changes the UI can come with a demo video recorded on the runner, which you watch on the card or in Telegram before you merge.
- A project can run review steps, a peer review and its own review skills, on every green pull request before a card counts as Finished.
- Your own Claude Code session can also group cards into stacks, set their dependencies and drive their designs.

### Improved

- The Overview shows live agent sessions, projects with their live state, recent activity and a seven-day spend trend.
- The card page is the full detail view, with each round’s pull request, commits, checks and run facts.
- Designs open on a device canvas with a tab per frame, for the devices you choose.

### Fixed

- A card that finishes before its checks turn green is merged once they do.
