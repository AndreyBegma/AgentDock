# Nautelle v0.15.0

Released 2026-10-23 · Runner: 0.15.0, released with this version (`runner-v0.15.0`, cut from the same `main` commit) ·
Changelog entry: `packages/shared/src/changelog.ts`

## Summary

A person's own Claude Code session can now drive the Board through the `nautelle` plugin, designs follow editable frame templates, sign-in can require a second factor, and the token-saving techniques are measured per successful card. This release needs runner 0.15.0 for the Board tools; on each machine, upgrade the runner and run `nautelle-runner setup claude` once (the local telemetry receiver now needs a token), and update the `nautelle` plugin to 0.6.0.

## What changed

### New

- Your own Claude Code session can work the Board: it lists, creates, runs and moves cards, answers their questions, takes one to do itself, and asks you to accept a finished card.
- A design follows a frame template for a page, a component or a flow, which a project can edit and each card, plan task and stack can choose.
- You can turn on two-factor sign-in with an authenticator app and recovery codes.
- Usage shows what each token-saving technique saves per successful card, and cards can try a technique side by side with a control group.
- A card’s model and effort follow the kind of work it is, and a round on Sonnet can hand itself over to Opus once.

### Improved

- The card detail opens with a compact header and tabs, and a card on the Board shows only what you act on.
- The app and the runner tell you when a newer runner is available.

### Fixed

- A card that hits a usage limit resumes by itself when the limit resets.
