The slot is a flex child of data-card-row="header", not an absolute overlay. Opacity toggles visibility ([li:hover_&], [li:focus-within_&], selecting), so the header's width is the same in every state. A test can assert that the slot is the header's first child and that no BOX_PLACE negative offsets remain.
