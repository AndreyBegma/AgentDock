What changes

1

Page header Changed

PageHeader with one solid primary, New issue. The meta line moves into the strip, so the header takes one line.

2

Stats strip New · C-339

Replaces three tall StatTiles with a single 64px row of five figures. Each cell links to where its figure is explained (OVERVIEW_TILE_HREF). When a figure fails to load it shows a dash and the reason, never a false zero. If glass-ui has no compact stat-strip, it is added there (ADR-0011).

3

Needs you, grouped C-340

Grouped by severity: Blocking (failing CI, a stopped orchestrator, an exceeded budget), Waiting on you (approvals and questions), then Setup. A setup need that repeats across projects collapses into one row with stacked project swatches and a disclosure, which ends the one-row-per-project flood. Setup rows now count toward the 5-row cap (NEEDS_YOU_SHOWN). Within a group, the oldest item comes first. Each row has one verb button.

4

Live sessions C-341

One row per live slot: the slot's hue dot, the issue key and title, the project swatch, the agent, the elapsed time, and a StatusPill. Waiting sessions sort first. Shows 5 rows, then "All sessions" (Fleet).

5

Recent activity C-342

A glass-ui timeline of the latest 5 workspace events, with status-coloured dots and the project swatch.

6

Projects with state C-343 · C-342

A dense list instead of cards. Each row: the square hue swatch, the orchestrator StatusPill, live slots and "need you" (warn), and a 7-day spend sparkline in the project hue with the 7-day total. Projects that need you sort first, then by last activity. A row opens the project's Board.

7

Layout C-339

At desktop: (≥1024px), two columns at 1.6fr / 1fr. Each block is its own component in components/overview/. Below 1024px it is one column in this order: Needs you, Live sessions, Projects, Activity. At 1440px everything above sits above the fold.
