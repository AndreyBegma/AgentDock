## Project coding rules

Follow every rule below in the code you write for this project.

1. **Bun only** — Bun is the package manager. Never run npm install or yarn; versions are pinned exactly.
2. **Prisma only in the API** — Import Prisma only in apps/api, through PrismaService. The web app talks to the API over HTTP.
3. **glass-ui components only** — Use only @andrewbehma/glass-ui components. A missing one is added to glass-ui, not written in the app.
4. **No any** — TypeScript strict everywhere. Never use any; narrow unknown instead.
5. **A bug fix ships its test** — Every bug fix comes with the *.spec.ts test that would have caught it, next to the code.

Changes apply to the next agent run; agents already running keep the prompt they started with.
